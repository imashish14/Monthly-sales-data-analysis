# Monthly-sales-data-analysis
Data Analytics Project: Excel, Python, SQL & Power BI

📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, from cleaning raw Excel data to building an interactive Power BI dashboard. It integrates Python, Pandas, MySQL, and Power BI to transform dirty data into meaningful insights and create a reliable data connection for reporting.

🛠️ Tools & Technologies

- Microsoft Excel: Source of raw data
- Python: Data processing and automation
- Pandas: Data cleaning and transformation
- MySQL: Data storage and management
- SQL: Database queries and data retrieval
- Power BI: Interactive dashboard and data visualization

🔄 Project Workflow

1. Data Import

- Imported raw and uncleaned data from Excel into Python.

2. Data Cleaning & Transformation

Used Pandas to prepare the dataset for analysis:

- Removed duplicate records.
- Converted column names to snake_case for consistent naming.
- Added new columns to enrich the dataset.
- Cleaned and transformed the data for further analysis.

3. MySQL Database Integration

- Established a connection between Python and MySQL.
- Loaded the cleaned dataset into MySQL database tables.
- Used MySQL as a centralized data source for storing and retrieving the processed data.

4. Power BI Dashboard

- Connected Power BI directly to MySQL.
- Built an interactive dashboard to explore and visualize the data.
- Enabled users to analyze key metrics and identify meaningful patterns through visual reports.

📊 Key Features

- End-to-end data processing workflow.
- Automated data cleaning using Pandas.
- Duplicate removal and standardized column naming.
- Python-to-MySQL database integration.
- Interactive Power BI dashboard.
- Direct SQL database connectivity for more consistent and maintainable reporting.

🎯 Project Objectives

- Improve data quality and consistency.
- Streamline data preparation and storage.
- Integrate Python, SQL, and Power BI into a single workflow.
- Make data easier to explore through interactive visualizations.
- Support data-driven decision-making.
